# Design Digest UA — план від нуля до запуску

Український Telegram-канал з новинами продуктового дизайну, керований AI-агентом на Claude + GitHub Actions. Бюджет: до $20/міс. Старт: одна людина (ти).

---

## 0. Стратегічна рамка

**Позиціонування (одне речення):** "Щоденний дайджест світового продуктового дизайну українською — для тих, кому ліньки читати 40 джерел самому."

**Чому ти, а не Vetrov / UX Collective / Sidebar.io:**
- Українська мова — нульова конкуренція в ніші
- Щоденна, а не щомісячна частота — більше engagement
- AI-driven curation — масштаб неможливий для однієї людини
- **Meta-aggregation: ти стоїш на рівень вище за конкурентів — твій агент аналізує не тільки первинні джерела, а й самі дайджести-конкуренти. Те, що покрили 3+ топ-куратори — твої "consensus picks". Те, що знайшов AI, але пропустили інші — "hidden gems". Жоден з конкурентів не може робити те саме, бо вони — твої вхідні дані.**
- Твій досвід як дизайнера = редакторський фільтр (важливо: ти все одно лишаєшся обличчям бренду, навіть з повною автоматизацією)

**Ризики, про які треба знати заздалегідь:**
1. Повна автоматизація без редакторського ока → за 2-3 тижні шум. Рішення нижче — quality gate + kill switch.
2. Telegram сам не дає коментарів — треба прив'язана discussion group.
3. Конкуренти у глобалі (UX Collective, Sidebar.io, Smashing) — англомовну версію запускай пізніше, коли укр-канал вже стабільний.
4. RSS-парсинг часом ламається — потрібен моніторинг.

## 4. AI-агент: технічна архітектура (день 4-7)

### Стек
- **Python 3.11**
- **GitHub** (приватний репо для коду)
- **GitHub Actions** — cron щогодини (безкоштовно: 2000 хв/міс)
- **Claude API** (claude-haiku-4-5 для scoring, claude-sonnet-4-6 для writing) — ~$5-10/міс
- **SQLite** як state (зберігаємо ID опублікованих новин — щоб не дублювати)
- **feedparser, requests, anthropic** — основні бібліотеки

### Pipeline (що скрипт робить кожен запуск)
```
1. Fetch RSS з sources.yaml (паралельно, 3 шари)
   - Шар 1: первинні джерела → нові статті
   - Шар 2: engagement-сигнали → бустимо score відомих статей
   - Шар 3: дайджести-конкуренти → consensus-аналіз

2. Dedupe по canonical URL і semantic similarity (embeddings)

3. Semantic clustering (Claude Haiku):
   - Об'єднуємо статті, що говорять про одне й те саме
   - Один кластер = одна тема = максимум один пост

4. Multi-source scoring (Claude Haiku) — оцінка 0-10:
   - Релевантність продуктовому дизайну (0-3)
   - Глибина (кейс/розбір цінніший за новину) (0-3)
   - +2 якщо HN > 100 points / Reddit > 500 upvotes / Product Hunt > 200
   - +1 за кожен дайджест-конкурент, що згадав тему (max +3)
   - −2 якщо це переказ статті, що вже виходила раніше

5. Класифікація:
   - score >= 8 + consensus >= 3 → 🔥 Consensus pick
   - score >= 9 + consensus == 0-1 → 💎 Hidden gem
   - score >= 8 і не підходить під 🔥/💎 → звичайний пост
   - інакше → відкидаємо

6. Claude Sonnet 4.6 пише пост:
   - 2-3 абзаци українською
   - TL;DR з ключовою ідеєю (1 речення)
   - Чому це важливо дизайнеру (1 речення)
   - Якщо consensus pick — згадуємо "цього тижня про це писали також X, Y, Z"
   - Посилання на оригінал
   - 2-3 хештеги (#ux, #designsystems, #ai, тощо)

7. Safety gate (див. розділ 5)
8. Опублікувати в Telegram Bot API
9. Записати в SQLite (URL, кластер, score, опубліковано так/ні)
```

### Спеціальні щотижневі автопости
- **Понеділок 09:00:** 🔥 "Що обговорював дизайн-світ цього тижня" — підбірка top-3 consensus picks за минулі 7 днів
- **П'ятниця 17:00:** 💎 "Те, що пропустили інші" — підбірка top-3 hidden gems
- **Перше число місяця:** "Дайджест місяця" — meta-stats: про що писали найбільше, які джерела видали найкращий контент, які тренди зростають

### Cron-розклад
- Запуск кожні **3 години** з 8:00 до 23:00 по Києву
- Якщо за запуск немає нічого 8+, нічого не публікується
- Максимум 3 пости на день (захист від спаму)

### Структура репо
```
design-digest-ua/
├── .github/workflows/
│   └── digest.yml          # cron job
├── src/
│   ├── main.py             # entry point
│   ├── fetch.py            # RSS збір
│   ├── score.py            # Claude scoring
│   ├── compose.py          # написання поста
│   ├── publish.py          # Telegram
│   └── db.py               # SQLite
├── sources.yaml            # список джерел
├── prompts/
│   ├── scoring.md          # промпт для оцінки
│   └── compose.md          # промпт для написання
├── state.db                # SQLite (gitignored)
└── requirements.txt
```

**Я можу написати весь цей код за тебе** — скажеш на якому етапі готовий — і ти просто скопіюєш у GitHub, додаси токени у Secrets, і воно полетить.

## 5. Safety gate (kill switch)

Це той самий компроміс між повною автоматизацією і human curation:

**Як працює:**
1. Скрипт згенерував пост
2. Замість публікації в канал — шле в твій особистий Telegram чат з кнопками `✅ Publish` / `✏️ Edit` / `❌ Skip`
3. Якщо ти **не відреагував за 15 хв** — автоматично публікується
4. Якщо натиснув Skip — пост викидається назавжди

**Чому це важливо:** статистично ти зловиш ~10-15% постів, які гірші за середній якісний рівень, або де AI неправильно щось зрозумів. Ці 10% і будуть різницею між каналом "як усі AI-боти" і каналом "де класно".

Якщо ти зайнятий або у відпустці — все одно публікується. Це auto, але з safety net.

## 8. Контент-план перших 30 днів

| День | Тип контенту | Хто робить |
|------|--------------|------------|
| 1 | Welcome post — манифест | Ти, вручну |
| 2-7 | 2-3 пости/день, AI-curated | Агент |
| 7 | Підбірка тижня "5 найкращих" | Агент агрегує |
| 14 | Твоя редакторська колонка | Ти, ~30 хв |
| 21 | Перший reach-out для реклами | Ти |
| 30 | Звіт перед аудиторією: "як живеться каналу" | Ти |

**Регулярні рубрики (генерує агент):**
- 🔥 **Consensus picks** (понеділок) — топ-3 теми тижня з cross-digest аналізу
- 💎 **Hidden gems** (п'ятниця) — те, що пропустили великі дайджести
- 📊 **Monthly digest** (1-е число) — мета-статистика місяця
- 🛠 **Tool of the week** — найкращий інструмент за upvotes Product Hunt + GitHub stars

**Регулярні рубрики (твоя редакторська рука):**
- ✍️ **Editor's note** (середа) — твоя думка про головну подію тижня (30 хв роботи)
- 💬 **"А як у вас?"** — питання до аудиторії, AI генерує на основі останніх постів

## 9. Метрики, монетизація, масштаб (місяць 2-6)

### Метрики
- TGStat.com — безкоштовний моніторинг
- Що відстежувати: підписники, ERR (engagement rate), VPR (views per post), темп росту
- Цільові показники для місяця 3: 1000+ підписників, ERR 30%+, VPR 60%+

### Монетизація (коли можна починати)
- **500+ підписників:** перші cross-promo з близькими каналами (взаємні згадки)
- **2000+ підписників:** платна реклама (бюро дизайну, школи, SaaS-продукти) — $30-100/пост
- **5000+:** спонсорство рубрик, афілейтні посилання на курси/інструменти
- **10000+:** свої продукти (платний канал з in-depth розбором, курс)

### Масштабування
- **Англомовна версія** після 3000+ укр-підписників — той самий агент, інший промпт, окремий канал
- **Twitter/X дублікат** — короткі картки з ключовою думкою
- **Email-newsletter** — щотижнева підбірка (Beehiiv, безкоштовний до 2500 підписників)
