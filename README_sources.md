# Sources — як працювати

Цей пакет дає тобі стартову базу 60+ RSS-фідів для AI-агента.

## Файли

- **sources.yaml** — головний конфіг. Усі джерела в 3 шарах (primary / signals / competitors), з вагами і тегами.
- **verify_feeds.py** — перевіряє кожен фід і генерує звіт.
- **sources_report.md** — створиться після першого запуску verify.

На виході отримаєш:
- Лог у консоль (✓ / ✗ біля кожного джерела)
- `sources_report.md` — markdown з таблицею та списком broken для заміни
- `sources_report.json` — для майбутньої автоматизації

## Що з цим робити далі

1. Запустити `verify_feeds.py` — побачити реальний стан
2. У `sources_report.md` подивитися секцію **❌ Broken**
3. Для кожного broken джерела:
   - Зайти на сайт, знайти RSS іконку у футері — замінити URL
   - Або видалити з yaml, якщо джерело реально мертве (додати у секцію `dead:`)
   - Якщо немає RSS на сайті — додати через rss.app (free до 5 фідів)
4. Перезапустити verify — повторювати, поки >90% живих

## Як працюють ваги (weight)

Кожне джерело має `weight` від 0.5 до 1.6. Це множник, який AI-агент застосовує до базового scoring:

- **1.6** — Built for Mars, Growth.Design (майже все варто публікувати)
- **1.5** — NN/g, Smashing, TLDR Design (топ-curation)
- **1.0** — дефолт
- **0.7** — Awwwards, SiteInspire (візуальні шоукейси, потребують сильної редакторської руки)
- **0.5** — Dribbble (надто шумно, тільки тренд-сигнал)

Можеш редагувати під свій смак — це впливає на те, який % контенту з джерела доходить до публікації.

## Як працюють 3 шари

**Шар 1 — Primary:** генерує статті для оцінки. Це твій основний контент.

**Шар 2 — Signals:** не додає нових статей, а **бустить score** статей з Шару 1, якщо вони з'явилися тут з високим engagement. Логіка: HN з 500+ points → score +2.

**Шар 3 — Competitors:** перевіряє, які зі статей Шару 1 згадані в інших дайджестах. Якщо 3+ незалежних дайджести згадали → 🔥 Consensus pick. Якщо score 9+ і 0-1 згадало → 💎 Hidden gem.
